Este repositorio contiene el **motor computacional de limpieza tensorial (Backend Microservice)** de Tzanix, denominado **Neural Gateway Core**.

A diferencia de un firewall que bloquea (como Q-Balam), Neural Gateway es un purificador profundo. Su algoritmo matemático está diseñado para interceptar tensores corruptos (NaN, Infinity, Adversarial Injections) dirigidos a LLMs, purificarlos estructuralmente y entregar la onda de datos limpia (HTTP 200 OK) al modelo de IA.

> *Nota: Este es un repositorio privado del motor. Para la interfaz web, visita \TZANiX-Neural-Gateway\.*
